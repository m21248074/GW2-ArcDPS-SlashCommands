# Slash Commands 1.0.0

GW2 的 arcdps 插件，以繁體中文按鈕執行表情指令，無需 Nexus。

## 功能

- 提供 60 個表情，分為「基本表情」與「需解鎖」分頁；「其他指令」提供 `/gg` 與 `/sc`。
- 每個按鈕分兩行顯示中文名稱與原始指令，文字置中，按鈕依視窗寬度自動換行。
- 可在目前分頁內搜尋中文名稱或英文指令。
- 勾選搜尋框旁的「瘋王說」後，只顯示活動使用的 18 個表情，並可在其中搜尋；切換時會清空搜尋文字。
- 沿用 arcdps 字體設定，不另外載入字體，不提供快捷鍵。
- 執行狀態、等待佇列、EngineTick 計數與執行緒資訊可在 arcdps 的插件設定畫面查看。

「需解鎖」依表情的取得條件分類，包含購買、成就、劇情與其他獎勵；插件不會偵測帳號實際解鎖狀態。中文名稱為本插件的介面翻譯，實際送出的仍是英文指令。

## 安裝與更新

1. 安裝 arcdps。
2. 完全關閉 GW2。
3. 解壓縮發布包，將 `arcdps_slashcommands.dll` 放入遊戲根目錄或 `bin64`，只保留一份。更新時替換原安裝位置的同名檔案。
4. 若要顯示中文，請先在 arcdps 設定支援繁體中文的字體。
5. 啟動遊戲並登入角色，在 **Slash Commands** 視窗點擊按鈕執行。

關閉視窗後，可到 arcdps 的 **Slash Commands** 設定畫面勾選「顯示指令視窗」重新開啟。移除插件前也須完全關閉遊戲，再刪除 DLL。

## 使用說明

- **瘋王說**：勾選後只顯示 18 個活動表情；聽到「Mad King says…」才做動作，未說這句時不要做動作。取消勾選後回到原分頁。
- **戰敗 `/gg`**：在遊戲支援的區域讓角色戰敗。
- **Snow Crows `/sc`**：開啟 Snow Crows 網站；也可直接在遊戲聊天框輸入 `/sc`。
- 按鈕目前執行固定指令，沒有自訂參數或 chat link 輸入功能。
- 搜尋文字、所選分頁與「瘋王說」篩選狀態不會在下次啟動時保留。視窗顯示狀態儲存於遊戲目錄下的 `addons/arcdps/arcdps_slashcommands.ini`；視窗位置由 arcdps 管理。

## 問題排查與限制

- 表情能否使用取決於帳號解鎖與遊戲限制。設定畫面顯示「呼叫已返回」只表示函式已返回，不代表遊戲接受該指令。
- `/sc` 聊天攔截失敗時會在設定畫面顯示錯誤；若指令執行功能正常，仍可使用網站按鈕。
- 指令或 EngineTick 定位失敗時，按鈕會停用。請查看主視窗的錯誤訊息、設定畫面的 EngineTick 計數，以及 `addons/arcdps/arcdps.log`。
- 指令排入佇列後，每次 EngineTick 最多執行一個指令，執行間隔至少為 250 毫秒，佇列最多保留 8 個等待請求。載入地圖、離開角色或渲染回呼逾時會清除尚未執行的請求。
- 插件呼叫遊戲內部函式並使用攔截機制，遊戲更新或其他插件可能影響相容性，也可能造成崩潰。更新或移除插件需完全重啟遊戲，不支援熱更新。

## 驗證

1.0.0 通過四組離線測試，涵蓋函式定位、DLL 與共用 ImGui 環境、指令佇列與設定，以及 EngineTick 參數、回傳值、執行緒與生命週期。

## 編譯

需要 Windows、Visual Studio C++ x64 建置工具與 CMake。在專案目錄執行：

```powershell
.\build.ps1
```

腳本會編譯、執行離線測試，並將 DLL、README 與第三方授權輸出至 `dist`。測試不會執行實際遊戲指令或開啟瀏覽器。

## 參考與第三方元件

功能參考自 [GW2-SlashCommands](https://github.com/gwdevcommunity/GW2-SlashCommands)。本版使用 arcdps 按鈕介面，未提供 Nexus 快捷鍵整合或對外自訂指令註冊 API。

隨附 Dear ImGui 1.92.7 與 MinHook，授權位於原始碼的 `third_party/imgui/LICENSE.txt`、`third_party/minhook/LICENSE.txt`，發布包則位於 `licenses` 資料夾。
